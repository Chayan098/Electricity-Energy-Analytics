
# Electricity & Renewable Energy Analytics Dashboard

## Project Description

This project is an interactive electricity analytics dashboard developed using Python, Streamlit, Pandas and Plotly.

It collects real-world electricity generation data from the Energy-Charts API by Fraunhofer ISE.

The dashboard helps users understand electricity generation patterns and analyze the contribution of renewable and non-renewable energy sources.

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Requests
- Energy-Charts API

## Features

- Explore electricity generation by country.
- View the latest total electricity generation.
- Calculate renewable energy contribution.
- Visualize electricity generation trends.
- Analyze the electricity energy mix.
- Compare renewable and non-renewable generation.
- Explore solar and wind energy trends.
- Identify major electricity generation sources.
- Download electricity data as CSV.

## Data Source

Energy-Charts API by Fraunhofer ISE:

https://api.energy-charts.info/

Website:

https://www.energy-charts.info/

No API key is required for the public API.

## Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder

```bash
cd energy-analytics-dashboard
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

### 5. Open in Browser

```text
http://localhost:8501
```
